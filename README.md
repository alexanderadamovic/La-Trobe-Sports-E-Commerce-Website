# La Trobe Sports

A multi-page sports retail website developed using HTML and CSS as part of my coursework at La Trobe University. The project focuses on page structure, navigation, styling, and creating a consistent user experience.

## Technologies

- HTML
- CSS

## Features

- Home page introducing the sports retail website.
- About page with information about the site.
- Products page showcasing sports products.
- Brands gallery.
- Contact page.
- Product reservation form with fields for customer details, product information, quantity, preferred pickup date, and comments.
- Navigation between pages and a back-to-top control.

## Project Structure

The website includes pages such as:

- `index.html` — home page.
- `about.html` — about page.
- `products.html` — product listings.
- `brands.html` — brands gallery.
- `contact.html` — contact page.
- `reservation.html` — product reservation form.
- `style.css` — shared website styling.

The repository may also contain image assets used by the pages.

## How to View

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the website navigation to explore the pages.

No additional installation is required for the static website.

## What I Learned

- Structuring web pages with HTML.
- Applying CSS for layout and visual consistency.
- Connecting multiple pages with navigation links.
- Designing forms and organising website content.

## Background

Created for university coursework while studying Information Technology (Software Engineering) at La Trobe University.

> The reservation form is a frontend demonstration; this project does not claim to process real orders or payments.
